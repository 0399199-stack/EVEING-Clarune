# 发行门禁

当前结论：**仅内部 Phase 0 PoC；不得作为已获商用许可的付费版本发布**。以下检查均需针对最终安装包及精确版本重新执行，而不是只看源码仓库。

| 门禁 | 通过条件 | 现在 |
|---|---|---|
| clean-room | 代码、资源、模型和二进制无 Upscayl / `upscayl-ncnn` 内容；来源清单可复核 | 规则已定，最终包待审 |
| 推理编译 | `Real-ESRGAN-ncnn-vulkan` 固定 MIT 提交；ncnn、glslang、libwebp 固定兼容且受支持的提交；本机真实图片推理通过 | 待完成 |
| 依赖安全 | 最终二进制/SBOM 无已知严重漏洞，尤其不使用旧 libwebp 解码用户输入 | 待完成 |
| 模型权利 | `MODEL_ALLOWLIST.json` 所有模型具备上游明确付费再分发授权，或记录法律风险签核 | **阻止付费发行** |
| 模型完整性 | 所有随包模型大小和 SHA-256 与批准清单一致，来源不是 Upscayl | PoC 样本已验证，发行包待审 |
| 法律声明 | MIT、BSD、glslang 复合许可、libwebp `COPYING` / `PATENTS` 等完整原文随安装包交付，关于页可打开 | 草案，待集成 |
| Microsoft 运行库 | 无 `vcomp140d.dll` 等调试文件；零售运行库的分发来源和许可可查 | 待完成 |
| 签名与供应链 | 自建 worker/安装包已签名；记录 SHA-256、构建工具链、编译参数与 SBOM | 待完成 |
| 功能验收 | 真图输出退出码 0、文件非零、完整解码、尺寸正确；原图哈希不变；中英 UI、安全 IPC 和授权边界测试通过 | 待完成 |

放行流程：每次发布先冻结依赖与模型清单，再生成最终 SBOM、扫描安装包、跑干净 Windows 机器测试、核对声明全文，最后由工程与法律/授权负责人分别签核。任一阻止项未通过，状态仍为内部 PoC。
