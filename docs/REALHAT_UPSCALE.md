# 自然超清 · Real-HAT（v6 本地预览）

主页面和批量「图片超清」均可选择「自然超清 · Real-HAT」。普通照片 x4plus 和动漫模型仍保留；新选项排在列表第一位，不强制替换原有默认或已恢复的批量参数。

## 功能范围

- 官方普通版 Real-HAT GAN x4；不是 Sharper 锐利版。
- 2× / 3× / 4×：均先真实 AI 4×，2× / 3× 再按目标尺寸缩小。
- 独立检测每种模型所需环境；缺失、损坏、依赖不全、CUDA 不可用或显存不足时明确报错，不静默改用其他模型。
- 单张进度来自实际分块数量；取消终止本次推理进程，进程退出后再清理临时图片，保留此前成功结果。
- 批量使用同一模型和参数，逐张处理；停止队列完成当前图片后不再处理剩余项目。
- 保存、修改格式或压缩已生成的主页面 AI 结果不重复执行推理。
- 保留透明通道，RGB 使用 AI，透明度从原图插值；不把透明度交给模型生成。
- 所有图片在本机处理；不自动下载、不上传图片、不修改 ComfyUI 或外部 Python 环境。
- 人像自然度改善不等于五官完全不变；文字和 Logo 的细小纹理也可能被重建。

## 当前本机如何使用

1. 打开 `EVEINGClarune_Preview_v6/EVEING Clarune.exe`。
2. 在主工作台「AI 模型」选择「自然超清 · Real-HAT」。
3. 等待独立环境检查显示已连接，导入图片，点击开始 AI 超清。
4. 批量入口中同样选择该模型，再导入队列、调整共享参数、开始批量处理。

当前工作目录已有经过验证的 `work/realhat-face-test` 外部模型目录。程序仅检查这一精确相对位置，或用户明确选择的目录，不扫描硬盘。如果整个项目移动导致解释器路径失效，需要重新配置。

## 独立运行环境目录

```text
所选模型目录/
  clarune-realhat.json
  models/
    Real_HAT_GAN_SRx4.pth
```

`clarune-realhat.json` 只需指定已有 Python 的绝对可执行文件路径：

```json
{"pythonExecutable":"D:/your-existing-environment/python.exe"}
```

在对应模型的高级设置中选择这个目录，而不是选择旧 ncnn 目录。配置按模型分别保存；已明确选择但失效的目录不会被其他路径偷偷替代。

本预览验证过 Python 3.13 / PyTorch 2.13.0+cu130 / Spandrel 0.4.2 / NumPy / Pillow 与 RTX 5070 Ti。检测会检查 HAT 架构支持及实际小型 CUDA 运算。其他版本或显卡尚未验证；当前 Real-HAT 入口要求可用的 NVIDIA CUDA 环境，不会静默切到 CPU。旧 ncnn 模型不受此要求影响。

程序随附的 `resources/realhat-worker.py` 为固定产品脚本，不执行模型目录提供的脚本。通过隔离模式启动 Python，不继承 PYTHONPATH 或用户 PATH，不安装依赖。

## 模型与处理参数

- 权重：170,277,017 字节；SHA256 `f5b1e3bbbb05147ca2beefcc715279cb647d7976cbda67d62ea7e6e20d5ffcc7`。
- 只接受该普通版权重，每次运行校验；`torch.load(weights_only=True)`，使用官方配置的 `params_ema` 严格匹配。
- FP32，禁用 TF32；分块 128 / 256 / 512、边缘扩展 32、窗口 16。128 更省资源，512 可能明显增加显存占用。
- 输入上限沿用原有 AI 限制：裁剪后 2.5 MP、每边不超过 4096；最大中间输出 40 MP。
- 非 16 倍数尺寸使用边缘填充，输出还原精确目标尺寸。1 像素等极小图片使用安全填充。
- 小型环境检查缓存 5 分钟；权重仍在状态检查及推理启动时校验。

## 打包边界

v6 是本机可运行预览，不是自带全部依赖的独立安装包。打包仅复制原有应用和新增适配脚本，**不复制模型、Python、PyTorch、CUDA 或 Spandrel**。换到另一台电脑，需要配置相应外部环境。

本轮不改变收费、激活和许可门禁。正式分发仍需分别审核模型、运行环境及转依赖的再分发要求，不将技术验证视为商业许可审核完成。

## 验证

- 单元测试包含固定模型验证、按模型路由、状态缓存、无错误回退、进度协议、取消/超时、异常退出和导入隔离。
- `tools/verify-realhat-v6.mjs`：真实 GPU 单张 2/3/4×、批量、透明图、保存不重复推理、跨页取消、安全关闭、恢复和实际海报测试。
- `tools/verify-realhat-ui-v6.mjs`：状态响应乱序、模型切换、独立缺失环境、中英文字和小窗口布局。
- `tools/verify-enhance-v5.mjs` 和 `tools/verify-upscale-v4.mjs`：原有通用/动漫模型回归。
- 测试使用独立临时用户配置，不改变用户当前打开的 v5 队列和设置。

最终证据在项目同级 `EVEINGClarune_RealHAT_v6_Review`。用户海报在实际应用中输出 4344 × 5792，去除全不透明 alpha 后与此前确认的 Real-HAT 测试图 RGB 像素完全一致。
