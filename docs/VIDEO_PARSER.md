- 本机 DNS 将平台域名解析到 `198.18.0.0/15` Fake-IP 段。仅当全部系统 DNS 答案均属于此段时，使用固定 `https://dns.alidns.com/resolve` 查询该域名的 IPv4 地址。仅发送域名，不发送作品 ID、路径、Cookie、媒体签名或历史；不改系统 DNS/代理设置。解析结果仍须全部通过公网校验，实际平台连接固定到这些地址。普通私网、混合私网、重定向与不安全目标仍被拒绝；解析器不跟随 DNS 服务重定向，响应限制 64 KiB、8 秒。
- 早期直连测试：修复前被 Fake-IP 地址检查拒绝；修复后旧详情端点返回 **403 / ACCESS_DENIED**。该旧路径没有下载成功，不能当作现行浏览器路径的验证结果。

- 用户确认后，接入软件自带 Electron 的独立浏览器会话，读取公开页面 `RENDER_DATA` 中与请求 ID 完全一致的 `app.videoDetail`。只抽取标题、作者、媒体等必要字段，不保留整份页面数据。当前适配器修订为原上游 SHA 加 `-browser1`，没有引入第二个第三方引擎。
- **真实视频链路通过**：作品 `7667114943409311017` 解析、软件预览和本地下载成功；1920 × 1080、584.122 秒、95,776,293 字节。下载文件 `Downloads/EVEING Clarune/Douyin/Clarune-test-7667114943409311017.mp4`，SHA-256 `1f06967f566f88d2899c96f263e394b9d72887cf2bd196803984df5df84c981d`。保存后另用隔离浏览器播放开头并定位末尾成功；未宣称逐帧完整解码或所有平台作品均可用。

## 当前实现与使用

左侧“视频解析”可展开/收起，其下只有“抖音去水印”。应用原先使用 React 页面状态导航，没有独立路由库或可展开菜单；现在由 `src/shared/navigation.ts` 集中维护页面与 hash 路径，子页面为 `#/video-parser/douyin`，父路径 `#/video-parser` 落到子页面。直接访问和刷新会展开并高亮子菜单。原来没有抖音入口、通用下载中心、视频数据库或素材库，因此没有旧入口迁移，没有改动原图片设置、队列或历史键，也没有新增素材管理系统。

粘贴作品短链接、视频/图集长链接或分享文案 → **开始解析** → 查看作品信息 → 主动预览或下载。解析只请求分享页面与作品元数据，不拉取完整视频、不创建素材文件、不加入下载队列。展示结果后可以请求必要的封面或第一张图。视频预览需要点击，默认静音。预览错误不影响已解析信息。

批量入口支持多行和原生文件对话框导入 UTF-8 TXT（最多 128 KB），最多 100 条去重后的输入；超限报错，不截断。有效链接先去掉无关分享参数，解析后按完整字符串作品 ID 再去重。批量中无效链接单独报错，不影响其余有效链接。只有全为空/无效时在页面本地拦截。解析并发为 1，默认启动间隔 1.2 秒；任务重解析也使用同一限速通道。

资源按钮只依据实际返回的资源出现：视频、图集、封面、音频。音频不从视频中提取。当前主引擎输出一个播放入口，因此不显示虚构的画质选择，也不承诺原画、4K。没有经验证的外部直链能力，当前不提供“复制视频直链”；“复制原链接”只复制规范化的作品来源。

每次解析新建不持久化的独立会话，无预加载桥、无 Node 权限、无弹窗/外部协议访问；拒绝权限申请及浏览器原生下载，关闭时清理会话。6 秒内未取得数据则显示页面，用户可自行处理平台验证；不自动点击验证控件。关闭窗口、取消解析或主程序退出会停止任务，浏览器解析最长 3 分钟。尚未针对实际人工验证码完成端到端验收；若平台新增验证资源域名，可能需要重新审核白名单。

此临时会话通过仅绑定 127.0.0.1、随机端口和随机认证的 CONNECT 通道联网：仅允许审核域名的 443 端口，DNS 公网检查并固定到实际 socket，TLS 仍由 Chromium 端到端验证，不解密或读取 Cookie。它不是第三方代理，不改系统代理/证书/DNS。浏览器逐请求白名单阻断媒体/CDN视频请求、遥测域名、WebSocket、非代理 WebRTC UDP 与社交写入；仅允许必要验证主机 POST。文件预览/下载使用独立受控传输，带固定公开站点 Referer/桌面 UA，不转发浏览器 Cookie 或认证头。

复用既有 `trustedFrame` 校验、contextIsolation/sandbox、CSP、预加载桥、许可证服务、原生文件对话框和窗口关闭等待机制。沿用现有玻璃卡片、按钮、主题与 i18next。图片输出注册表只接受图片/PDF，未放宽为任意路径；视频的“在文件夹显示”由任务 ID 查询自身已保存路径。下载沿用已有输出授权原则，在主进程校验激活。

下载/预览只接受解析会话和资源 ID，主进程持有实际 URL。页面只得到随机 `clarune-media://preview/<token>` 能力地址。切换/清空/离开页面释放预览；取消旧解析后，其迟到结果不会覆盖新结果。

直连传输只允许抖音分享域名及独立的 CDN 白名单。DNS 查询得到的所有 IPv4/IPv6 地址均须通过公网校验，且实际连接使用这批已验证地址，防止重新解析到私网。每个直连重定向重复校验，最多 5 跳；无 Cookie/认证头转发。元数据最大 4 MiB，直连连接/响应头 10 秒、旧直连接口 30 秒、独立浏览器解析 180 秒、媒体空闲 60 秒。没有引入第三方代理或自有遥测。

## 保存、暂停与恢复

默认目录为系统 Downloads 下 `EVEING Clarune/Douyin`，用户通过原生对话框更换后记住；已入队任务保留其原保存位置。文件名清理 Windows 特殊字符和保留名称、限制长度。同名文件递增后缀，不覆盖；图集创建独立目录，以 `001`、`002` 等顺序命名。扩展名由实际文件特征识别，未知格式失败，不硬改为 JPG/MP3。默认不转码或加工。

下载并发默认 2，可选 1–3，最多保留 100 个任务。传输流式写入目标目录内 `.clarune-<任务ID>-<资源ID>.part`；按真实字节数/速度显示进度，长度未知时不显示百分比。完成后校验非空、已知长度、媒体签名，以及支持格式的容器/结束标记，再通过同盘独占硬链接原子发布完整文件，删除该任务临时文件。当前没有引入 ffmpeg，检查**不等于完整解码每一帧/每种音频编码**。单个资源上限 4 GiB。

当前进程内仅当同一资源、强 ETag、偏移及总长度均匹配时追加 206 数据；200 从头覆盖自己的临时文件；416 只触发一次重新下载，不能表示完成。续传校验失败时不追加，下一次重试从头开始。弱/缺失 ETag 时提示可能重新下载。可恢复网络错误额外重试最多 2 次，使用退避；403/404 允许重新解析一次并清空旧部分，不拼接新旧资源。429 失败明确显示，并让后续队列等待至少 Retry-After 时长；验证、权限和删除错误不反复自动重试。

暂停保留部分文件和当次安全续传信息。取消立即中止请求，仅清理该任务未完成的 `.part`，保留已完成图集图片和其他文件。图集部分失败不能算完成；重试保留成功项，并检查成功文件是否仍存在。文件被外部移动/删除后，显示明确错误。

持久化文件为应用 `userData/video-parser-v1.json`，版本化结构为 1；记录保存目录、并发、任务及最近 100 条解析历史。保存作品来源、ID、必要展示信息、路径及状态，**不保存签名媒体 URL、Cookie 或认证头**。重启把未完成任务恢复为暂停，不自动下载；用户继续后重新解析并从头下载未完成文件，保留已完成图片。清空解析历史不会删除下载文件。异常退出发生在发布文件与记录写入之间时，重新下载可能生成带后缀的副本，既有文件仍受保护。
