## 使用与未覆盖边界

1. 保留完整 `EVEINGClarune_Preview_v3` 文件夹，运行其中 `EVEING Clarune.exe`。旧版未导出的内存队列不能迁移到新版；原图片文件不受影响。
2. 本机安全保存采用硬链接排他发布。FAT/exFAT/网络盘未实机验证；不支持该操作时明确提示换用本机 NTFS，不能承诺所有外接盘兼容。
3. 队列恢复不自动重新导出，也不自动判定中断前哪些文件已保存；请按恢复提示核对输出，避免重复处理。历史记录仅在界面收到成功结果后记录，不能当作崩溃恢复日志。
4. 预览拖动水印的临时层不包含最终 JPEG/有损编码带来的像素误差；松手后显示实际编码预览，导出仍由同一后端处理。
5. 本轮未做磁盘写满、强制杀进程、断电、网络断开、多 GPU/混合 DPI 极限测试，也不承诺全部 446 种字体或动画在所有硬件达到固定帧率。
6. 先前通过测试 API 设置整页 125%/150% 缩放的诊断风险未列为已解决；发布界面未提供该入口，本轮验证标准界面倍率及舒适/紧凑字体。窗口按最小 980×680 内容尺寸使用。
7. AI 超清引擎、模型发布审计、机器码激活 UI 和收费发布流程仍未接入；这次升级解决本地图像工具和交互，不应标记为已完成商用版。
