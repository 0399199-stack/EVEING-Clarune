# EVEING Clarune · 冰蓝白玻璃与本地图片工具

更新日期：2026-09-17。

## 界面与交互

- 无山影、云纹或景色壁纸，背景为干净的冰蓝白渐变；玻璃边缘高光、柔和折射与蓝色悬浮投影。
- 导航分为工作区、图片工具、应用；活动底板平滑移动，按钮按压反馈，页面淡入。遵循系统“减少动态效果”；拖动裁剪、对比线、缩放不添加滞后动画。
- 顶栏副标题改为“AI 超清影像引擎”；窗口、任务栏和界面沿用同一 EVEING Clarune 图标。
- 大预览保留滚轮缩放、拖动平移、1:1、适应窗口、原图与导入对比图的滑动分隔。
- 图片工具也使用可缩放画布：滚轮围绕鼠标位置缩放，支持直接输入缩放百分比、1:1 和适应窗口；裁剪/水印模式下用空格＋拖动或鼠标中键平移。
- 所有可调数值参数支持直接输入，百分比、角度等适用项同时保留滑条；输入与画布预览同步。
- 参数面板独立滚动；本地图片工具导出按钮固定在底部，最小窗口仍可达。
- 设置保留中英文即时切换、深浅主题、完整品牌简介及关于信息。

## 可以实际使用的功能

| 工具 | 行为 |
| --- | --- |
| 批量本地处理 | 添加多张图片、选工具并调参数、一次选择输出文件夹；逐项进度、结果和停止按钮 |
| 尺寸与格式 | 调整像素宽高，锁定比例或自由尺寸；输出 PNG / JPG / WebP |
| 压缩图片 | 1–100 质量滑条与输入框，步长 0.1；真实编码预览与实际输出大小 |
| 手动裁剪 | 在原图拖框、数值坐标、自由或固定比例；裁剪按方向校正后的原图像素计算 |
| 水印 | 本机已安装字体、文字或图片/Logo；预设位置、自定义 X/Y、拖动位置、透明度、字号/颜色或相对宽度 |
| 圆角 | 按输出像素设置半径，PNG / WebP 保留透明区域 |
| 旋转 | 左右 90 度快捷按钮和连续角度调节 |
| 翻转 | 水平、垂直翻转，可与其他编辑叠加 |
| 图片合并 PDF | 添加、排序、删除图片；一图一页，自适应图片尺寸、A4 竖向或 A4 横向完整适配 |

图片队列与编辑配方在工具间保留，每个图片工具均可一键批量导出；“仅导出当前预览”只处理当前图。“重置全部编辑”清空配方。PDF 使用自己的原始图片队列，不应用图片工具编辑。

批量尺寸锁定比例时，指定宽高为边界框，每张图片等比适配；关闭锁定则统一拉伸。裁剪区域按固定参考图的相对位置应用到其他图片，切换当前预览不会改变已保存的裁剪参数。不同宽高比图片的裁剪框也会按宽高分别缩放。

图片水印提示“建议使用透明背景的白色图片 / Logo”。X/Y 为水印左上角在可移动范围内的百分比，0%/100% 对齐两侧边缘；输出预览内的水印框可直接拖动定位，本机字体选择会参与真实导出。

增强页格式下面也有压缩质量滑条与“导出当前图片”。有导入对比图时导出该图，否则导出原图；界面明确说明这不是 AI 增强。

所有输出经过本机编码；单图/PDF 路径来自原生保存框，批量只选择一次文件夹。独占创建文件，已有文件不会被覆盖；批量同名文件自动编号。逐项失败、保存、取消分别显示，参数或队列变更后清除旧结果。

批量“处理完当前图片后停止”会保留已经完成的文件。批量处理中正常关闭窗口也会等待当前项编码和写入收尾，再关闭并停止后续项；仍在选择目录阶段可直接关闭，不会等待模态框形成死锁。

## 明确边界

- **AI 推理、自动超清结果、批量 AI 处理、激活码 UI 仍未接入。** 不以普通缩放替代或冒充 AI 超清；对比图仍需手动导入。
- 质量滑条可连续拖动，底层编码器按整数质量工作；不保证每张图片都变小。
- PNG 100 为无损编码，低于 100 会量化颜色。JPG 不支持透明，圆角/旋转空白区域填白。
- 单图最大 64 MiB、4000 万像素、单边 16384 像素；批量与 PDF 均最多 60 张。批量输入总量 128 MiB，包括每项重复附带的 Logo 数据；超限提示减少数量或缩小水印图片。PDF 输入总量 128 MiB。
- 不支持动态图，当前导出移除 EXIF 等元数据。PDF 内部图片按质量编码成 JPEG，透明区域为白底。
- 预览程序未代码签名，不是收费发行版或安装器，不注册文件关联、不修改固定任务栏快捷方式。
