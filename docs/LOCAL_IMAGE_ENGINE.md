# 本地图像工具实现说明

此模块是实际可单图或批量导出的本地图片处理工具，不是 AI 超分辨率模型。AI 增强引擎、批量 AI 超清及激活流程仍未接入。

## 数据与处理顺序

渲染层通过文件选择器读取用户选择的图片字节，IPC 仅传 `Uint8Array` 和编辑参数，不接受读取文件的路径。处理模块没有网络上传、HTTP 请求或远程处理逻辑；文字水印通过经过转义的 Pango 标记渲染，内置 SVG 仅用于圆角蒙版，不读取外部资源。

处理顺序：EXIF 方向校正 → 原图像素坐标裁剪 → 尺寸调整 → 旋转 → 水平/垂直翻转 → 水印 → 圆角 → 编码。裁剪坐标基于方向校正后的原图；水印字体与圆角半径按最终输出像素计算。翻转在水印前执行，不会将水印文字镜像。

仅受信主窗口的主框架可调用处理接口。单图/PDF 导出路径来自 Electron 原生保存对话框，建议文件名会移除路径符号。同目录临时文件以 `wx` 创建，完整写入、同步、关闭后通过排他硬链接发布最终文件，再移除临时名称；目标已存在则失败，不覆盖原有文件。取消原生保存框不写入。当前本机磁盘已验证；不支持硬链接的文件系统安全报错并提示改用本机 NTFS，不退化为可能暴露半文件的写入方式。网络盘、FAT/exFAT 未实机验证。

## 批量任务与退出

- 批量页及每个图片工具使用同一个可编辑队列和共享配方。点击“开始批量导出”后，只选择一次目标文件夹；主进程逐项编码、独占创建文件，同名文件自动添加 `(1)` 等编号，保留原文件。
- 每批最多 60 张，合计输入 payload 不超过 128 MiB。计算方式为所有原图字节，加上每张任务附带的图片水印字节；例如 20 张图片使用同一个 2 MiB Logo，水印部分计入 40 MiB。前端导出前预检，后端再次校验。单个图片/Logo 仍受 64 MiB 和像素限制。
- 裁剪坐标保存于固定参考图，切换预览不会重复缩放配方。自由裁剪按相对区域映射；选择 1:1、4:3、16:9 等预设时，每张图在映射区域中心保留该固定比例（允许像素取整误差）。“原始比例”按每张图自己的宽高比处理。数字修改选区会明确切回自由模式。裁剪框可移动、拖动四角、方向键微调，Alt+拖动重画。
- 锁定尺寸比例时，指定宽高作为边界框，每张图片等比完整适配（`inside`）；关闭锁定时全部拉伸到指定像素尺寸（`fill`）。旋转角度、字号、圆角按共享数值应用；水印位置按可移动范围同步。
- 同时仅允许一批任务；每项有真实保存、失败或取消结果，单项失败不阻止后续图片。进度仅发送给发起任务的受信主框架；修改参数或队列后清除旧结果，避免把上次导出误认为当前配置已保存。
- “处理完当前图片后停止”保留已完成文件，不启动后续图片。正常点击关闭窗口时，同样先停止后续项，等当前项编码、写入及同步收尾后再关闭；重复点击不能绕过等待。若仍停留在选择目录阶段，允许窗口直接关闭以释放原生对话框，不产生文件。
- 单图/PDF 保存同样受关窗保护：已进入写入阶段则等待安全提交；未开始写入的编码/对话框可以安全取消。保护不等待无关预览。导出期间阻止页面重载，发布构建移除开发菜单和重载快捷键。强制结束进程、系统崩溃或断电未做破坏性测试；可能遗留隐藏临时文件，不声称能保证断电恢复。
- 图像/PDF 队列缓存在本机，重新打开只恢复内容和参数，不自动继续导出；清空对应队列会删除恢复内容。本地历史仅记录成功输出的信息，失败项不会显示为成功。输出位置入口只允许主进程实际保存并登记的路径。

## 格式、质量与限制

- 输入/输出格式：静态 PNG、JPEG、WebP。拒绝 SVG 输入、动画、多页和无效图片。
- 单个输入或输出不超过 64 MiB；输入/输出图像不超过 4,000 万像素，单边不超过 16,384 像素。
- 压缩滑条接收 1–100 的小数；底层 JPEG、WebP 和 PNG 量化编码器使用四舍五入后的整数质量。滑条表示质量，不是保证的压缩率或文件体积；部分小图/已压缩图片可能不变小。
- PNG 滑条值正好为 100 时采用无损编码；低于 100 切换为有损调色板量化，颜色或细节可能减少。JPEG/WebP 使用有损编码。
- PNG/WebP 保留旋转空白处及圆角的透明度；JPEG 不支持透明，统一用白色填充。
- 尺寸支持拉伸到指定尺寸，或完整等比适配。旋转支持任意有限角度（−360° 至 360°），会按需扩展画布，不裁掉旋转内容。
- 水印支持文字或本地图片/Logo、五个预设位置和自定义 X/Y、透明度、字体大小/图片相对宽度。建议使用透明背景的白色图片/Logo；导出的文字与图片位置均可拖框定位。
- 字体列表通过隐藏窗口的固定 PowerShell/.NET `InstalledFontCollection` 只读枚举本机字体族，不安装字体、不执行用户输入的脚本、不接收任意字体文件路径。指定字体必须在已安装列表中，经过转义交给 Sharp/Pango；默认使用中文字体回退，不打包商业字体。实际字形先测量再适配，过长文字与过大的水印会缩小到可放置区域。
- 水印 X/Y 内部按剩余可移动范围保存比例：`left = round((输出宽 - 水印宽) × X)`，Y 同理。界面可切换百分比/像素；0%/100% 对齐两侧。主进程返回实际边界和预览所需底图/透明水印层，拖动时水印实时移动，提交使用相同坐标。吸附可关闭；安全边距线为可选参考线，不会裁切图片或强制改变导出尺寸。
- PDF 按输入顺序一图一页；页面选择自适应图片尺寸（96 DPI 对应 0.75 pt/px）、A4 竖向或 A4 横向。A4 为 24 pt 留白、等比完整适配、不裁切。最多 60 张，总输入/输出不超过 128 MiB；图像以设定质量转为 JPEG 嵌入，透明处为白色。PDF 使用独立原图队列，不应用图片工具配方，不是 OCR 或可编辑文字 PDF。
- 主进程最多同时执行 2 个处理任务，最多等待 4 个，超出返回 `BUSY`。Sharp 的异步本地处理不在渲染线程执行；处理大图仍会使用相应 CPU 和内存。

所有可调数值都有输入方式，包括尺寸、裁剪坐标、角度、质量百分比、不透明度、图片水印比例、X/Y、字号、圆角与查看缩放；适用项同时保留滑条。图片工具画布支持滚轮以鼠标位置为中心缩放、1:1、适应窗口及缩放数值输入；裁剪/水印编辑中使用空格加拖动或鼠标中键平移，避免与编辑拖动混淆。

## 依赖、重建和打包

直接生产依赖固定为 `sharp@0.35.4` 和 `pdf-lib@1.17.1`，版本及完整依赖关系记录在 `package.json`、`pnpm-lock.yaml`。正常环境执行 `pnpm install --frozen-lockfile` 后构建。

本轮 npm 二进制包下载超时，开发环境使用已安装共享运行时中相同版本的完整依赖副本，未修改共享运行时；锁文件通过本地已验证元数据生成。pnpm 11 默认在运行脚本前校验安装状态并可能重新下载；当前环境可临时设置 `pnpm_config_verify_deps_before_run=warn` 后运行构建/测试，或直接调用 `node node_modules/typescript/bin/tsc`、`node node_modules/electron-vite/bin/electron-vite.js build`、`node node_modules/vitest/vitest.mjs run`。这不是后续标准安装步骤，不需要修改系统级配置。

`tools/package-preview.ps1` 使用 `tools/export-production-deps.mjs` 从实际安装目录复制生产依赖闭包，包含 Sharp Windows `.node` 与 libvips DLL，不依赖上述共享运行时的绝对路径。不会复制开发依赖树、工作目录或用户密钥。
